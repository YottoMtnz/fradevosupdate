# Fradev OS web screenshots

La página detecta automáticamente estas capturas si existen:

- `fradev-desktop.webp` — escritorio general (principal, ideal 16:9)
- `fradev-fraglass.webp` — fraGlass / transparencia
- `fradev-compat.webp` — compatibilidad / Puente / Android / Windows
- `fradev-control-center.webp` — Control Center
- `fradev-android.webp` — una app Android ejecutándose en Fradev OS

Recomendación: exportar a WebP con 1600–2200 px de ancho para la captura principal y 1000–1600 px para las secundarias. No hace falta tocar `index.html`: al copiar las imágenes con estos nombres, sustituyen automáticamente los placeholders.
