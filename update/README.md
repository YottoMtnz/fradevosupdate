# Fradev OS — canal estable de actualizaciones

Este directorio es el endpoint público oficial del canal de actualizaciones de **Fradev OS 1.0 Stable 2**.

- **Producto:** Fradev OS
- **Canal:** stable
- **Base:** 1.0 Stable 2
- **Revisión pública actual:** R12
- **Creador:** Fraudy Martínez Madruga

`manifest.json` indica al sistema cuál es la revisión estable publicada y qué paquete firmado debe utilizar.

**R12 — Fradev Windows Integrado estable** conserva R1–R11 y consolida la integración de aplicaciones Windows como ventanas independientes dentro de Fradev OS.
