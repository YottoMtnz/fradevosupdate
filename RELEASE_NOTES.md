# Fradev OS 1.0 Stable 2

**Creado por Fraudy Martínez Madruga.**

Fradev OS 1.0 Stable 2 es la base pública actual del proyecto, diseñada como un escritorio Linux moderno para desarrollo, productividad, compatibilidad, juegos y asistencia local con Fradev AI.

## Destacados

- Debian 13 como base del sistema.
- Escritorio con identidad visual fraGlass.
- Control Center y Fradev OS Software.
- Entorno de desarrollo amplio.
- Compatibilidad ampliada y herramientas para juegos.
- Fradev AI local opcional.
- Canal estable de actualizaciones firmadas.
- Revisión pública actual disponible a través del canal estable: **R6**.
