## ¿Qué es Fradev OS?

Fradev OS es una estación de trabajo de escritorio orientada a personas que quieren **crear, desarrollar, experimentar y aprovechar mejor su PC** sin tener que elegir entre potencia y facilidad de uso.

La idea es simple: un sistema moderno para el día a día, con herramientas de desarrollo, una experiencia visual propia y caminos de compatibilidad para ampliar lo que puedes hacer desde un solo escritorio.

### Lo que define a Fradev OS

- **Desarrollo listo para empezar** — Python, C/C++, Rust, Go, Java, Web, contenedores, bases de datos, virtualización y más.
- **fraGlass** — la identidad visual de Fradev OS: limpia, translúcida, configurable y enfocada.
- **Compatibilidad ampliada** — soporte para muchas aplicaciones de Windows, Android y juegos compatibles.
- **Steam + Game Lab** — juegos, emulación y herramientas para experimentar con proyectos propios.
- **Devices** — herramientas para impresoras, escáneres y otros dispositivos del día a día.
- **Control Center** — un punto central para revisar el sistema y acceder a sus funciones principales.

Puedes navegar, trabajar, programar, gestionar archivos, usar herramientas de desarrollo, jugar y conectar dispositivos sin cambiar de entorno ni convertir cada tarea en una configuración interminable.

## Compatibilidad

Fradev OS amplía las posibilidades del escritorio, pero no promete compatibilidad universal.

Algunas aplicaciones pueden depender de componentes propietarios, DRM, anti-cheat, controladores específicos, arquitectura de CPU o conexión a Internet. Cuando una aplicación o dispositivo necesita algo especial, Fradev OS intenta hacerlo visible en lugar de ocultarlo.

## Para usuarios avanzados

Fradev OS también deja el control técnico al alcance de quien lo quiera.

```bash
# Diagnóstico general del sistema
fradevctl doctor

# Estado completo de los perfiles de desarrollo
fradevctl dev status full

# Comprobar el estado del canal de actualizaciones
fradevos-update check

# Ver servicios con fallos
systemctl --failed
```

Estos comandos forman parte de la instalación de Fradev OS 1.0 y son útiles para diagnóstico, soporte y validación rápida.
